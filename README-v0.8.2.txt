ArikePreorder v0.8.2 - Compact Account & KYC Status

Changes:
- Removed Account Setup percentage, Security and duplicate Verification summary cards.
- Account header now shows only full name, @username and KYC status.
- Email and phone are private and only appear inside Personal Information > Edit.
- Personal Information is collapsed by default.
- Personal Information can edit name, username, email, phone and location.
- KYC badge states: green Verified, red Not Verified, yellow Needs Attention, neutral Under Review.
- Clicking KYC badge opens the KYC management section.
- Existing Seller Centre and marketplace features preserved.

Keep your existing backend/.env file when replacing the project.
